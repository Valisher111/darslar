Darslar — o'qituvchi uchun qo'llanma

Baholar jurnali, darsdagi quiz va Live o'yin, talabalar uchun Telegram bot — hammasi bitta saytda. Bepul. Ma'lumotlaringiz faqat sizning Google hisobingizda turadi.

1. O'rnatish (bir marta, 15–20 daqiqa)

Kerak: Google hisobi (Gmail), kompyuter (o'rnatishni telefonda qilish noqulay), Telegram.

  1. Valisher bergan shablon havolasini oching → Fayl → Nusxa yaratish (File → Make a copy). Nomini o'zgartiring, masalan Darslar — Karimova. Bundan keyin faqat shu nusxada ishlaysiz.
  2. Bir marta: script.google.com/home/usersettings sahifasida Google Apps Script API ni On qiling. (Bu platformaga o'zini nashr qilish va keyinchalik yangilanish imkonini beradi.)
  3. Nusxangizni oching va 10–15 soniya kuting: yuqori menyuda Darslar chiqadi. Darslar → Install / open Darslar ni bosing.
  4. Google ruxsat so'raydi: Continue → hisobingiz → Advanced (Kengaytirilgan) → Go to Darslar (unsafe) → Allow.
    «Google hasn't verified this app» degan ogohlantirish normal holat. Bu skript sizning o'zingizning nusxangiz, unga faqat siz ruxsat beryapsiz. Hech kim sizning jadvalingizni ko'ra olmaydi.
  5. Yana Darslar → Install / open Darslar ni bosing. «Darslar is installed» oynasi chiqadi → Open Darslar.
  6. Ochilgan saytda parol qo'ying (kamida 6 belgi). Saytni brauzer xatcho'piga (bookmark) saqlang. Telefonda ham shu havola orqali shu parol bilan kirasiz.
Saytni keyin har doim jadvalingizdagi Darslar → Install / open Darslar menyusidan yoki saqlangan xatcho'pdan ochasiz.

2. Guruh va talabalar

Guruh qo'shish

  1. Saytda Groups → + Add group.
  2. Guruh nomi (HEMIS'dagidek), fan nomi, dars kunlari (masalan Du va Chor), birinchi dars sanasi, 1- va 2-blokdagi darslar soni (odatda 15 + 15).
  3. Mustaqil ta'lim: PW1 + PW2 (5 + 5 ball) yoki MT1–MT10 (har biri 1 ball).
  4. Talabalar ro'yxatini HEMIS'dan nusxalab qo'ying: har qatorda bitta F.I.Sh.
  5. Xohlasangiz dars mavzularini ham qo'ying (har qatorda bittasi, «Unit 1 - Mavzu»). → Create group.

Jadvalingizda shu nomli varaq barcha formulalar bilan paydo bo'ladi: Joriy (jami), Joriy (20), Oraliq, reytinglar, MI, ON, Yakuniygacha, YN, Jami (100), NB soni. Kunlik baho 0–10; 0 = darsga kelmagan.

Talabalar

  • Groups → Students: yangi talaba qo'shish (ro'yxat bilan), ismni tuzatish (Rename), guruhdan chiqarish (Remove).
  • Remove bosilganda talabaning qatori baholari bilan birga avval arxivga saqlanadi, keyin jurnaldan o'chadi. Xato bo'lsa, Removed students → Restore bilan baholari bilan qaytadi.
  • Jurnal varag'ida qatorlarni qo'lda o'chirmang yoki qo'shmang. Buni saytda qiling, shunda formulalar buzilmaydi.

Dars sanalari

Groups → Lesson dates: bayram yoki jadval o'zgarsa, sanani bosib yangisini tanlang. Ustundagi baholar, dars mavzusi va shu darsning quizi birga ko'chadi.

Guruhni yashirish

Groups → Settings → Hide group: guruh saytdan va botdan yo'qoladi, varaq va baholar jadvalda qoladi. Show again bilan qaytadi.

3. Talabalar uchun Telegram bot

  1. Telegram'da @BotFather → /newbot → botga nom bering (masalan Karimova darslari) va _bot bilan tugaydigan username yozing → BotFather token beradi.
  2. Saytda Settings → Student bot → tokenni qo'ying → Save.
  3. Connect my Telegram → Open Telegram → Start. Endi talabalar so'rovlari sizga botda Approve/Reject tugmalari bilan keladi.
  4. Bot havolasini guruhlaringizga yuboring. Talaba Start bosadi → guruhini va ismini tanlaydi → siz tasdiqlaysiz → talabaga shaxsiy sahifasining havolasi keladi (baholari, davomati, quiz natijalari, uy vazifalari).
  5. Botni guruhingizning Telegram chatiga ham qo'shing va u yerga istalgan xabar yozing. Bir daqiqadan keyin Groups → Settings → Telegram group chat ro'yxatida shu chat chiqadi, uni tanlang. Shundan so'ng dars oxirida «Finish lesson» baholar rasmini shu chatga yuboradi.

4. Darsda

  • Today: bugungi darslar, mavzu, baho kiritilgani.
  • Grades: baholarni kiritish (katakni bosing). Attendance rejimida kelmaganlarni belgilaysiz (0).
  • Quizzes: Start as test — talabalar quizni o'z telefonida ishlaydi, baho jurnalga o'zi yoziladi. ▶ Live game — Kahoot kabi o'yin: proyektorda QR kod, talabalar telefonda javob beradi.
  • Dars oxirida ✓ Finish lesson: bo'sh kataklarga 0 (kelmagan) yoki o'rtacha baho qo'yiladi, baholar rasmi guruh chatiga ketadi (oldin rasmni ko'rsatib, so'raydi).
  • Deadlines & PW: topshiriq muddatlari. Bot talabalarga muddatdan 3 kun va 1 kun oldin eslatadi.

5. Quizni Claude bilan tayyorlash

Quizni qo'lda ham yozish mumkin (Quizzes → + New quiz). Claude bilan esa tezroq bo'ladi:

  1. Claude'ga darslik sahifasini (PDF, rasm yoki matn) bering va shunday yozing: «Darslar quiz JSON: Unit 5, 10 MC + 3 TF + 1 gap + 1 match, faqat til (grammatika va so'z boyligi)». darslar-quiz skilini qo'shsangiz, format o'zi to'g'ri chiqadi: darslar-quiz.zip ni yuklab oling va Claude sozlamalaridagi Skills bo'limida «Upload skill» orqali qo'shing.
  2. Claude bergan JSON blokni to'liq nusxalang → saytda Quizzes → Paste from Claude → qo'ying → Continue.
  3. Bitta quiz bo'lsa, u tahrirlagichda ochiladi: tekshirib, Save bosing. Bir nechta quiz bo'lsa, hammasi birdaniga saqlanadi.

Format (skilsiz ham Claude tushunadi, shu namunani unga ko'rsating):

{"title": "Unit 5 - Food and Drink", "unit": "Unit 5", "duration_min": 10,
 "questions": [
  {"id":"q1","type":"mc","prompt":"I'd like ___ water, please.","options":["a","some","any","many"],"answer":1,"explain":"some — in offers and requests"},
  {"id":"q2","type":"tf","prompt":"'Menu' is a countable noun.","answer":true,"explain":"a menu, two menus"},
  {"id":"q3","type":"gap","prompt":"How ___ sugar do you take?","answer":"much","accept":["much"],"explain":"much + uncountable"},
  {"id":"q4","type":"match","prompt":"Match the halves","pairs":[["a cup","of tea"],["a slice","of bread"],["a bottle","of water"],["a bowl","of soup"]]},
  {"id":"q5","type":"order","prompt":"Put the words in order","items":["Would","you","like","some","cake?"]}
 ]}

MC: 4 variant, answer — to'g'ri variant raqami (0 dan). TF: true/false. Gap: accept — qabul qilinadigan barcha shakllar. Match: 4–6 juft. Order: so'zlar to'g'ri tartibda yoziladi, platforma o'zi aralashtiradi.

Yangilash

Valisher platformani yaxshilaganda: Settings → Gradebook and updates → Check for updates → Update now. Taxminan yarim daqiqa ketadi. Jurnal, talabalar va quizlarga tegilmaydi. Sayt sahifalari esa hammada o'zi yangilanadi.

O'z Firebase'ingiz (ixtiyoriy)

Live o'yin umumiy bepul serverda ishlaydi: barcha o'qituvchilar uchun bir vaqtda taxminan 100 o'yinchigacha. Live'ni katta guruhlar bilan tez-tez o'tkazsangiz, o'zingizning bepul serveringizni ulang (10 daqiqa):

  1. console.firebase.google.com → Add project → nom bering (Google Analytics — off).
  2. Build → Realtime Database → Create database → Location: europe-west1 → Start in locked mode.
  3. Build → Authentication → Get started → Sign-in method → Anonymous → Enable.
  4. Realtime Database → Rules: hamma matnni o'chiring, firebase-rules.json dagi matnni qo'ying → Publish.
  5. Project settings (tishli g'ildirak) → Your apps → Web (</>) → nom: darslar → Register. Chiqqan firebaseConfig = { … } blokini nusxalang.
  6. Saytda Settings → Live game server → qo'ying → Save → sahifani yangilang.

Muammo bo'lsa

  • Menyuda «Darslar» chiqmadi — sahifani yangilang va 15 soniya kuting.
  • «One more step» qayta-qayta chiqsa — usersettings sahifasini jadval qaysi Google hisobida bo'lsa, o'sha hisobda ochganingizni tekshiring (o'ng yuqoridagi rasm). Brauzerda bir nechta hisob bo'lsa, ko'pincha boshqa hisobda yoqilgan bo'ladi. Yoqqandan keyin 2–3 daqiqa kuting.
  • Baribir chiqsa — qo'lda nashr qiling (2 daqiqa): jadvalda Kengaytmalar (Extensions) → Apps Script → Deploy → New deployment → tishli g'ildirak → Web app → Execute as: Me, Who has access: Anyone → Deploy → Web app URL ni nusxalang. Keyin jadvalda Darslar → Connect web app URL → qo'ying → OK. «Open Darslar» tugmasi chiqadi.
  • Saytda «Please sign in again» — parolingiz bilan qayta kiring. Parolni unutsangiz, Valisherga yozing.
  • Bot javob bermayapti — Settings → Student bot «connected» ekanini tekshiring. Bot bir daqiqa ichida javob beradi (00:00–06:00 da xabarlar ertalabgacha kutadi).
  • Ism xato yozilgan — Groups → Students → Rename (jurnalda, botda va natijalarda birga o'zgaradi).
  • Jadvaldagi _p_ bilan boshlanadigan yashirin varaqlar platformaniki. Ularni o'chirmang.

Darslar — V.A. Tangriyev (DTPI) loyihasi. Sayt umumiy; har bir o'qituvchining baholari va talabalari faqat o'zining Google jadvalida saqlanadi.
